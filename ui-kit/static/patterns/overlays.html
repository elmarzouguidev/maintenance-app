Patterns

Drawer and bottom sheet

admin-drawer and admin-sheet: native dialogs for navigation and phone choices.

Navigation drawer

admin-drawer on a native <dialog> (focus trap, Escape, focus return): slides from the start edge (the end edge in right-to-left), 240 ms; opacity only under reduced motion. A click on the backdrop closes it.
