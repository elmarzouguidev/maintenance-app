Date picker

x-admin.date-picker: date, date and time, time only, native on phones.

Date, date and time, time only

The submitted value is the hidden input: "Y-m-d", "Y-m-d H:i" (with-time) or "H:i" (time-only). Keyboard: arrows by day and week, Home/End, PageUp/PageDown by month, Enter chooses, Escape closes and returns focus.
