Select and searchable select

x-admin.form-select is a native select. x-admin.form-select2 adds a search field (combobox, arrows, Enter, Escape); the submitted value is a hidden input with the same name.

Segmented radio

Native radios in a fieldset: arrow keys move the choice, and the form posts name=value like a select. Nothing is checked unless the value matches.

Checkboxes and switch
