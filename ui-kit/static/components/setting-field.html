Settings fields

x-admin.setting-field: one settings field of any type.

Every type

One settings field: text, email, password, url, number, time, textarea, select, file (current image and a live preview of the chosen one) or toggle.

Imprimée sur les factures et les contrats.

Fichier choisi : . Il sera enregistré avec le formulaire.

PNG transparent recommandé.

Affiche le schéma du véhicule au départ et au retour.
