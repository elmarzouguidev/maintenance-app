Components

Alerts and messages

x-admin.alert, flash messages (x-messages) and the validation summary (x-messages.errors).

Types

success, error (or danger), warning, info. Errors are announced immediately (role="alert"), the others politely (role="status"). Dismissible by default.

La réservation a été confirmée.
Le véhicule n’est pas disponible sur cette période.
La caution n’est pas encore sécurisée.
Le retour sera enregistré dans l’agence courante.
Blade 
<x-admin.alert type="success" message="La réservation a été confirmée." />
<x-admin.alert type="error" message="Le véhicule n’est pas disponible sur cette période." />
<x-admin.alert type="warning" message="La caution n’est pas encore sécurisée." />
<x-admin.alert type="info" message="Le retour sera enregistré dans l’agence courante." />

Not dismissible, with rich content

Use dismissible="false" for a state the user must see (an access notice, a locked record). The slot accepts markup.

Cette facture est émise : elle ne peut plus être modifiée. Créer un avoir
Votre abonnement se termine dans 5 jours.
Blade 
<x-admin.alert type="warning" :dismissible="false">
    Cette facture est émise : elle ne peut plus être modifiée. <a href="#" class="underline">Créer un avoir</a>
</x-admin.alert>
<x-admin.alert type="info" :dismissible="false" message="Votre abonnement se termine dans 5 jours." />

Flash messages (x-messages)

The layouts render x-messages under the topbar: one alert per session flash (success, status, error, warning), set with redirect()->with(...).

La réservation RES-2026-0148 a été confirmée.
Le véhicule n’est pas disponible sur cette période.
La caution n’est pas encore sécurisée.
Blade 
<x-messages />

Validation summary (x-messages.errors)

Above a long form: every validation error of the request. Each field also shows its own error (see Text fields).

Des erreurs sont survenues.

  • Le kilométrage au retour doit être supérieur ou égal au kilométrage au départ (24 500 km).
  • L’adresse e-mail doit être une adresse valide.
  • Les notes ne peuvent pas dépasser 500 caractères.
  • Choisissez l’agence de départ.
  • Choisissez un client.
  • Indiquez le niveau de carburant.
  • La date de retour doit être postérieure à la date de départ.
  • Le fichier doit être une image ou un PDF de 5 Mo au plus.
  • Le préfixe ne peut contenir que des lettres majuscules.
